# Schema Coverage Lab

Research into MC/DC-inspired semantic test coverage for JSON Schema Draft 2020-12.

This repository starts with research, mathematical qualifications, counterexamples, and an implementation handoff. Implementation and testing follow in staged draft pull requests. No pull request is to be merged automatically.

Status: repository initialized; research and staged proposals are in preparation.

MC/DC-inspired schema coverage is an experimental criterion, not a certification claim or a replacement for validator code coverage.
