# Frozen bounded study design

Protocol fixed before this experiment's first run, 2026-11-09. Inputs are in `study.json` (content-hashed by the experiment manifest). These are selected diagnostic cases, not a random sample of real schemas.

- Subjects: 20 authored pure-v1 schemas covering semantic boundaries and 12 official-derived schemas from the already pinned MIT-licensed suite. For each allOf/anyOf/oneOf/not file, select its first two admitted logical groups. Add the first admitted type/const/enum/Boolean group as four atomic controls. Preserve exact group indices/provenance.
- Generate one deterministic pool per subject, cap 48. Report truncation and rejected numeric representations. Never infer all-JSON completeness from these recipes.
- Compare decision-outcome greedy, predicate-outcome greedy, strict-independence pair-aware greedy, boundary-first and random selection on exactly that frozen pool at distinct-test budgets 2, 4, 8 (capped to pool size). Coverage-directed methods fill unused budget deterministically by ID after gains are exhausted; boundary-first uses schema literals/exact thresholds before neighbors/midpoints, then primitive representatives. Random uses seeds 0 through 19 without replacement.
- Score all methods from the same oracle-agreed pool observations. Report decision, predicate and independence coverage separately. Zero feasible target denominator is N/A. Random repetitions are nested within schemas, not independent additional subjects. Aggregate random scores within a schema before computing macro schema means.
- Also reduce each full pool to preserve its witnessed strict-independence obligations. Preserve both endpoints and replay the reduced evidence. Exact minimization is tested separately on pools <=16; do not call the general greedy result minimum.
- Optional mutation probe is included: local numeric bound shifts +/-1, type replacement, const replacement, enum-member removal, Boolean flip, applicator replacement/removal and double-not. Deduplicate well-formed admitted mutants and cap 32 per subject. Save every operator/path/schema and pool killing IDs. A mutant with no root-validity discrepancy on this pool is **pool-indistinguishable**, not globally equivalent. Report its count; do not silently discard it. No mutant equivalence solver is used.
- Distinguish generation/analysis/index/mutant-classification preprocessing from final-suite size and selection time. This is an offline selection study, not a fair end-to-end online generation efficiency contest. Record wall-time nanoseconds and per-subject traced Python peak memory; platform-specific times are descriptive only.
- Report raw per-schema/method/budget/seed outcomes, aggregate descriptive statistics, negative findings and limits. Do not infer superiority or causality from coverage preservation by construction. No p-values or population-level confidence claims are planned for this selected corpus.

Run `python tools/run_experiments.py` from the repository root. The implementation, commands, outputs and hashes are included in the final evidence manifest. The study completes bounded artifact evaluation; it does not complete full-draft support or establish first-ever novelty.
